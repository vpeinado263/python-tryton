# Python, PostgreSQL y GNU Health

Repositorio de prácticas del curso Desarrollo de Software Aplicado a Sistemas de Gestión Hospitalaria y Tecnologías Biomédicas. Reúne ejercicios de programación con Python y Tryton, consultas SQL e investigación de la estructura de un sistema de información hospitalaria real.

Prácticas 1 y 2 — PostgreSQL con una base simulada

Se trabajó con PostgreSQL 16 en Docker y DBeaver, utilizando la base ficticia hospital_practice.

Actividad 1 — Primeras consultas: consultas SELECT, selección de columnas, filtros, ordenamiento y limitación de resultados.

Actividad 2 — Indicadores hospitalarios: consultas con relaciones entre tablas (JOIN), funciones de agregación (COUNT), agrupamientos (GROUP BY) y filtros de grupos (HAVING) para obtener indicadores.

Ambas actividades incluyen archivos SQL y sus respectivos informes PDF en evidencia_entrega.

Prácticas 3 y 4 — Exploración y aplicación en GNU Health

Se utiliza una máquina virtual con GNU Health y PostgreSQL para estudiar el esquema real de la base de datos y las relaciones entre sus entidades.

Actividad 3 — Exploración del esquema real: identificación del entorno, inspección de tablas y columnas, análisis de claves primarias y foráneas y exploración de relaciones entre pacientes, citas, profesionales y evaluaciones. Incluye consultas de solo lectura, evidencias e informe PDF.

Actividad 4 — Trabajo final GNU Health: espacio destinado a integrar los conocimientos de SQL y aplicarlos a un caso concreto sobre la base real de GNU Health, documentando las consultas, su propósito y sus resultados.

Prácticas de Python y Tryton

Las carpetas dia-1, dia-2 y dia-3 reúnen ejercicios progresivos de Python, clases y métodos, y la construcción de un módulo de práctica para Tryton, incluyendo modelos, vistas XML y configuración del módulo.

Objetivo general: desarrollar habilidades de programación, consultas SQL y análisis de estructuras de datos aplicadas a sistemas de gestión hospitalaria, avanzando desde una base simulada hacia el entorno real de GNU Health.
